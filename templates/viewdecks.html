Welcome to our decks page

This is where you will find a list of all the decks and other content you have created (except for tests which can be found under account > tests).

You can do a lot of different things with these decks, here is the functionality so far:

  • Study deck: if you want to study an individual deck.

  • Edit deck: if you want to edit the existing cards, add new cards, edit the deck properties...

  • Share deck: Use this if you want to share this with your fellow users. Just enter their email address. (or a comma separated list of email addresses)

  • Download as CSV: If you want to download the deck as a comma seperated list (useful to read in excel for example).

  • Export to Anki: If you are a die hard Anki fan you can export your decks to their platform.

  • Create test: Use this to build a test based on your deck. Simply follow the instructions on each page.

  • See source files: If you have chosen to save the content that you uploaded, or if you have used the transcription function you will be able to find that data here.

  • Info: Here you will find information about your deck.

  • Delete: If you want to delete the deck. Be careful this is irreversible.
